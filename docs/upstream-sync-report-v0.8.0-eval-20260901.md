# Upstream 同期評価・動向分析レポート (2026年9月1日版)

## 概要

本ドキュメントは、オープンソース「Open GENAI (源内)」の Upstream リポジトリ (`https://github.com/hirokawaguchi/open-genai`) における最新更新（コミット SHA: `5de2e5a` / `v0.8.0` / PR #40〜#44）の評価結果および本プロジェクトの開発・セキュリティ方針に基づく採択／見送り判断を記録したレポートです。

---

## 1. Upstream 最新状況（コミット・機能更新サマリー）

Upstream における最近の主要な更新内容は以下の通りです：

1. **提案実装第2弾: `patchform-app`（オンライン申請フォーム一式）および `docmaker` (マイ手続き)**
   - 庁内/庁外向けオンライン申請フォーム作成、申請束（作業台）、マイ手続き、受付テーブル・ステータス管理等の追加。
   - 関連依存関係 `cryptography==50.0.1` への更新。
2. **Dify チャット UI ストリーミング最適化 (PR #42)**
   - トークン配信中の scrollIntoView 間引き（rAF化）および `/apps` ルートでのフッター隠蔽による画面カクつき防止。
3. **未起動オプションアプリの「おすすめ」非表示 (PR #43)**
   - `doccheck` や `patchform` などのオプトインコンテナが未起動の場合、おすすめアプリおよびサイドバーから非表示化。
4. **LLM プロバイダ直接接続と Anthropic `extra_body` 対応 (PR #44)**
   - `backend/app/llm.py` で OpenAI / Anthropic / Gemini へ直接接続を可能にし、Anthropic 送信時に `extra_body`（`max_tokens`）を設定。
